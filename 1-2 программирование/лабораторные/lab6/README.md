# Лабораторная работа 6

Учебный клиент-серверный Java-проект для работы с коллекцией объектов `Vehicle`.

Проект разделён на модули `common`, `client` и `server`. Клиент читает команды пользователя и отправляет запросы серверу по TCP, сервер хранит коллекцию и возвращает ответы.

## Основные возможности

- загрузка коллекции из JSON-подобного файла;
- хранение коллекции `Vehicle`;
- добавление и обновление элементов;
- удаление элементов по `id` и по условию;
- фильтрация по полям;
- подсчёт элементов по количеству колёс;
- выполнение команд из файла через `execute_script`;
- сохранение коллекции обратно в файл;
- логирование работы сервера через Log4J2;
- автодополнение команд по `Tab` в интерактивном режиме;
- Javadoc-комментарии на русском языке.

## Модули проекта

```text
common/
└── src/       # общие классы: request, response, io, data

client/
└── src/       # клиентское приложение и парсинг клиентских команд

server/
└── src/       # сервер, обработчик команд, storage, parser

scripts/       # примеры скриптов и данных
resources/     # ресурсы проекта
lib/           # внешние библиотеки: JLine и Log4J2
logs/          # файл логов сервера после запуска
```

## Команды программы

- `help` — вывести справку по доступным командам;
- `info` — вывести информацию о коллекции;
- `show` — показать все элементы коллекции;
- `add` — добавить новый элемент;
- `update id` — обновить элемент по `id`;
- `remove_by_id id` — удалить элемент по `id`;
- `clear` — очистить коллекцию;
- `save` — сохранить коллекцию в файл, серверная команда;
- `execute_script file_name` — выполнить команды из файла, клиентская команда;
- `exit` — завершить клиент или сервер;
- `head` — вывести первый элемент коллекции;
- `add_if_max` — добавить элемент, если он больше максимального;
- `remove_greater` — удалить элементы, превышающие заданный;
- `count_by_number_of_wheels numberOfWheels` — посчитать элементы с указанным количеством колёс;
- `filter_by_fuel_type fuelType` — вывести элементы с указанным типом топлива;
- `filter_starts_with_name name` — вывести элементы, имя которых начинается с заданной строки.

## Запуск

Для запуска сервера нужно указать переменную окружения `FILE_NAME`, в которой хранится путь к файлу с коллекцией.

Компиляция модулей:

```bash
mkdir -p out/common out/client out/server
javac -d out/common common/src/**/*.java
javac -cp out/common -d out/client client/src/**/*.java
javac -cp "out/common:lib/*" -d out/server server/src/**/*.java
```

Запуск сервера:

```bash
FILE_NAME=scripts/data.json java -Dlog4j.configurationFile=resources/log4j2.xml -cp "out/common:out/server:lib/*" server.ServerMain 5555
```

Запуск клиента:

```bash
java -cp out/common:out/client client.ClientMain localhost 5555
```

Пример запуска скрипта внутри программы:

```text
execute_script scripts/FirstFile
```

## Примечание

Это учебный проект, поэтому код сделан простым и понятным. Для обработки
нажатия `Tab` используется библиотека JLine, для логирования сервера - Log4J2.
